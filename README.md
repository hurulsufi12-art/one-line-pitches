One sentence, 196 characters, that would convince a friend who has never
coded to let an AI agent build their first app idea on make.fun.

> Just tell it your idea the way you'd tell me, and make.fun's AI agent
> will build your first real app, one you can open tonight — no code, no
> setup, and if you don't love it, we change it together.

## How it works

`main.py` (Python 3.13, stdlib only) writes that sentence to
`/output/entry.txt`. No network, no model calls, no randomness — the same
bytes on every run.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Test

```sh
python3 tests/test_entry.py
```
